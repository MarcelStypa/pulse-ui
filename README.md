# pulse-ui

Shared Angular component library with Storybook.

Part of the [Pulse](https://github.com/MarcelStypa/pulse) platform. See the overview repo for architecture and ADRs.

## Stack
- Angular library (ng-packagr), Storybook
- Published as @marcelstypa/pulse-ui to GitHub Packages
- Design tokens as CSS variables

## Development
- `npm test`, `npm run lint`, `npm run build`, `npm run storybook`

## Status
Scaffold only. See the roadmap in the overview repo.

## AI-assisted development
This project is built with an AI coding assistant (Claude Code), openly and by design. The rules that govern its use (human review, verification before trust, attribution, no secrets) are documented in [docs/ai-workflow.md](docs/ai-workflow.md), and the assistant is bound by [CLAUDE.md](CLAUDE.md) and [docs/](docs/).
